# 1. Record architecture decisions

* Status: accepted
* Date: 2026-08-25

## Context and Problem Statement
We need a standard way to document architectural decisions for our bioinformatics API so new contributors understand our design choices without relying on tribal knowledge.

## Decision Outcome
Chosen option: "Use Architecture Decision Records (ADRs)", because it is a proven standard in the open-source community. We will store these in `docs/adr/`.
